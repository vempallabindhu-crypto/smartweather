1. Objectives:

1.To develop a web-based application that provides real-time weather information for any city.

2.To display important weather details such as temperature, humidity, wind speed, rainfall, and feels-like temperature.

3.To provide a 5-day weather forecast for better travel planning.

4.To provide smart travel suggestions based on the current weather conditions.

5.To create a responsive and user-friendly interface that works on desktops, tablets, and mobile devices.

6.To use a weather API to retrieve live weather data dynamically.

3. Features:

🔍 City Search: Users can enter any city name to search for weather information.

🌡️ Current Temperature: Displays the current temperature and feels-like temperature.

💧 Humidity: Shows the current humidity percentage.

💨 Wind Speed: Displays wind speed in km/h.

🌧️ Rain Information: Shows current precipitation.

☀️ Weather Condition: Displays conditions such as clear sky, cloudy, rain, fog and thunderstorms.

📅 5-Day Forecast: Provides weather conditions and temperature for the next five days.

✈️ Smart Travel Suggestions: Gives recommendations for clothing, items to carry and suitable travel activities.

📱 Responsive Design: Works on desktop, tablet and mobile screens.

⚠️ Error Handling: Displays an error message when an invalid city is entered or the API cannot be reached.

⏳ Loading Indicator: Shows a loading message while weather data is being fetched.
